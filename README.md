# اپ اندروید «ورود» (Login App)

اپ ساده اندروید با صفحه ورود (Login)، ساخته‌شده با **Kotlin**.

- **نام کاربری:** `mobile`
- **رمز عبور:** `1234`

---

## دانلود فایل APK

این پروژه به‌گونه‌ای تنظیم شده که به‌صورت **خودکار** با GitHub Actions کامپایل می‌شود:

1. وارد این مخزن (Repository) در گیت‌هاب شوید.
2. روی تب **Actions** کلیک کنید.
3. روی آخرین اجرای «Build APK» کلیک کنید (سبز رنگ یعنی موفق).
4. پایین صفحه، در قسمت **Artifacts** فایل **Varud-APK** را دانلود کنید.
5. فایل zip دانلودشده را باز کنید؛ فایل `app-debug.apk` را به گوشی بفرستید و نصب کنید.

> هنگام نصب، اگر گوشی پیام «نصب برنامه‌های ناشناس» داد، اجازه نصب را بدهید (به‌دلیل اینکه اپ امضای رسمی گوگل‌پلی ندارد).

---

## تغییر نام کاربری و رمز عبور

فایل زیر را باز کنید:

```
app/src/main/java/com/varud/app/MainActivity.kt
```

در این فایل، داخل شرط ورود، مقدارهای `mobile` و `1234` را با مقادیر دلخواه عوض کنید. بعد از تغییر، با push کردن جدید، اپ دوباره به‌صورت خودکار ساخته می‌شود.

---

## اجرا در Android Studio (اختیاری)

اگر بخواهید اپ را روی کامپیوتر اجرا یا تغییر دهید:

1. پروژه را در Android Studio باز کنید (File > Open).
2. منتظر بمانید تا Gradle Sync تمام شود.
3. گوشی را با USB وصل کنید یا شبیه‌ساز (Emulator) را اجرا کنید و دکمه Run را بزنید.

## ساختار پروژه

```
├── .github/workflows/build.yml   ← ساختن خودکار APK روی گیت‌هاب
├── app/
│   ├── build.gradle              ← تنظیمات ماژول اپ
│   └── src/main/
│       ├── java/com/varud/app/   ← کد Kotlin (دو صفحه ورود و خوش‌آمد)
│       ├── AndroidManifest.xml
│       └── res/                  ← طراحی صفحات، رنگ‌ها، نوشته‌ها و آیکن‌ها
├── build.gradle                  ← تنظیمات کل پروژه
└── settings.gradle
```

## امکانات

- صفحه ورود با اعتبارسنجی نام کاربری و رمز عبور
- پیام خطای فارسی برای ورودی خالی یا اشتباه
- آیکن چشم برای نمایش/مخفی کردن رمز عبور
- صفحه «خوش آمدید» با نام کاربر و دکمه خروج از حساب
- رابط کاربری تیره مدرن، راست‌به‌چپ (فارسی)
- سازگار با اندروید ۷٫۰ (API 24) به بالا
